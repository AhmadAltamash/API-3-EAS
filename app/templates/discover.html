How this is different from Search Buyers: Search Buyers only finds companies that show up in a search engine or directory listing right now - which is why it runs dry over time. This asks Gemini to name companies it already knows about (the same thing as manually asking ChatGPT for a list), then tries to confirm each one for real by visiting their actual site. When that succeeds, you get a "Live-verified" lead. When a site blocks the fetch but Gemini genuinely knows a published trade email, you get an "AI-recalled, unverified" lead instead - still saved, still clearly labeled either way, never disguised as one when it's the other.
